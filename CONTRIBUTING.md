# Contributing

Contributions that improve correctness, documentation, tests, reproducibility or operational safety are welcome.

## Workflow

1. Open an issue for substantial changes.
2. Create a focused branch.
3. Add or update tests when behavior changes.
4. Keep examples free of credentials and production-specific data.
5. Submit a pull request explaining the problem, approach and trade-offs.

Prefer small, reviewable changes over broad rewrites.
